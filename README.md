# Digital Cyber Hub

Build Phase 1 of 'Digital Computers & Cyber Cafe' (ডিজিটাল কম্পিউটার ও সাইবার ক্যাফে) using the attached templates (digital_computer.html and admin_panel.html). Implement the front-end layout with shop & owner info, service/product list with prices & reviews, location and contact details, header navigation, quick WhatsApp/Gmail reachout, and an admin/user login entry.
